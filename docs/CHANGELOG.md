# 版本记录

## 1.12.0 — 2026-11-14

**悬浮窗现在可以单独选择主题**。主窗口用玻璃、悬浮窗用像素，或其他任意搭配。

右键悬浮窗 → **悬浮窗主题**：跟随主窗口（默认），或玻璃、小组件、纸墨、像素、赛博朋克、千禧、黏土、液晶。托盘和右上角 ⋯ 菜单也有同样入口，所选主题重启后保留；颜色与浅色/深色仍跟随主窗口。

本次也包含未单独发布的 1.11 改进：五套新主题的悬浮窗各有自己的画法，3 种样式 × 8 套主题共 **24 种搭配**。像素是缺角边框与方块进度，赛博朋克是霓虹切角与分段圆环，千禧是复古窗口与立体饼图，黏土是柔软立体面板，液晶是数码管与 60 格刻度圈。

| 下载包 | 说明 | EXE 大小 |
| --- | --- | --- |
| `work-cheer-1.12.0-windows-full-x64.zip` | 完整版，自带 Electron 内核 | 102.7 MB |
| `work-cheer-1.12.0-windows-lite-x64.zip` | 轻量版，依赖系统 Edge WebView2 和 .NET Framework 4.8 | 1.8 MB |
| `work-cheer-1.12.0-offline-web.zip` | 浏览器打开 HTML；网页没有桌面悬浮窗，页面与 1.10 相同 | HTML 约 0.68 MB |

**升级**：先在托盘或右上角 ⋯ 菜单中退出旧版，再打开新版。工资、计时记录和悬浮窗位置继续沿用；完整版与轻量版仍各自保存数据。

**验证**：最终完整版 EXE 18 项隔离启动检查、轻量版 11 项（含从完整版格式迁移数据）均通过。检查覆盖独立选主题、8 主题 × 3 样式、跟随主窗口、主窗口外观不变及重启后保留；48 组主题绘制对比通过。自动检查不等于人工验收，轻量版真实鼠标操作、新主题在不同系统缩放下的观感仍待用户试用。

Windows 发布均为 x64 未签名便携程序；只内置 2026 年假期，收入为估算。本次不更新 Sites 在线站点。下载包含说明与许可，SHA256SUMS.txt 用于校验 ZIP。

## 1.10.0 — 2026-11-13

新增五套有独立布局、材质和数字字体的主题：

- **像素**：八位机边框、点阵数字。
- **赛博朋克**：霓虹切角面板，深色发光。
- **千禧**：上世纪末的灰色窗口、立体按钮。
- **黏土**：圆润的软质面板和立体控件。
- **液晶**：数码管数字，深色为发光显示屏。

加上玻璃、小组件和纸墨，共 **8 套主题 × 8 种颜色 × 浅色/深色/自动**。两个 Windows 版本及离线网页都已包含新主题；像素与液晶数字字体为本项目自绘。
