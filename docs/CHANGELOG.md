# 版本记录

## 1.9.0 — 2026-11-07

本次同时提供完整版和轻量版，下载一个即可：

| 下载包 | 适合谁 | EXE 大小 |
| --- | --- | --- |
| `work-cheer-1.9.0-windows-full-x64.zip` | 希望自带浏览器内核 | 102.7 MB |
| `work-cheer-1.9.0-windows-lite-x64.zip` | 已有 Edge WebView2 和 .NET Framework 4.8 | 1.7 MB |
| `work-cheer-1.9.0-offline-web.zip` | 直接用浏览器打开 | HTML 约 0.6 MB |

- 完整版仅保留中英文语言包，启用最高压缩；功能沿用现有版本。
- 轻量版复用主界面和计算规则，三款悬浮窗由 C# 原生绘制。
- 轻量版首次启动尝试复制完整版的设置和记录，之后两边独立保存。
- 完整版最终文件已通过 16 项隔离检查，轻量版通过 8 项；轻量版真实鼠标拖动、缩放、右键与托盘仍待人工试用。
- 两版均为 Windows x64 未签名便携程序；系统共享运行时不计入轻量版 EXE 大小。
- 只内置 2026 年假期，收入为估算；本次不更新 Sites 在线站点。

解压后运行包内 EXE。附使用说明、第三方许可和 SHA256SUMS.txt。

## 1.8.0 — 2026-11-05

- 完整 Windows 窗口改为无边框，自绘悬浮窗、菜单、最小化、最大化和关闭按钮；保留窗口拖动。
- 三款悬浮窗跟随当前主题、颜色和浅色/深色外观。
- 提供玻璃、小组件、纸墨三种布局，以及独立的八种颜色和浅色/深色/自动设置。
- 保留今日收入、下班倒计时、工作进度、小目标、暂停与本地记录。
- 保留 2026 中国大陆放假与调休补班及单日手动覆盖。
- 本次 GitHub 发布加入中文带图 README、开发说明、网页 CI、Windows 与离线网页下载。
